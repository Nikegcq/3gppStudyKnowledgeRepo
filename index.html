0骨架 ≠ 编码

顶层 nrWaveformGenerator 只调度；比特/CRC/Polar/LDPC/调制在下列 nr* 公开函数里。

setup / validateConfig配置校验、采样率、端口
processAndGenerateCSIRS / SRSRS → reservedREs（内部）
processAndGeneratePDCCH内部调 nrDCIEncode → nrPDCCH
processAndGeneratePXSCH内部调 DL-SCH → nrPDSCH
ofdmModAndCombineBWPOFDM 合成（无调制）
addSSBurst内部调 nrBCH → nrPBCH / nrPSS / nrSSS

CORESET 无比特，只是 PDCCH 的 RE 容器。调用链可在 info.WaveformResources 的 DCIBits/Codeword/ChannelSymbols、TransportBlock/Codeword 字段对照验证。

1五问速查

① 比特

MIB/TB：配置 DataSource 或随机 → info.*.TransportBlock / DCIBits

② CRC

nrBCH（BCH 24-bit）· nrDCIEncode（24-bit⊕RNTI）· DL-SCH 链（TB/CB）

③ 速率匹配

nrBCH→E=864 · nrDCIEncode→E · DL-SCH nrRateMatchLDPC→G

④ Polar

nrBCH / nrDCIEncode 内部（38.212 §7.1 / §7.3）

⑤ 调制

nrPBCH/nrPDCCH=QPSK · nrPDSCH=QPSK…1024QAM · 底层 nrSymbolModulate

nrBCH BCH 编码 = CRC+Polar+RM E=864

cdblk = nrBCH(trblk,sfn,hrf,lssb,idxoffset,ncellid)
% trblk: 24×1 BCCH-BCH-Message
% sfn, hrf: SFN / 半帧位
% lssb: 4|8|64
% idxoffset: L=4/8 时 k_SSB(0..31)；L=64 时 i_SSB(0..63)
% cdblk: 864×1 码字 → 交给 nrPBCH

nrPBCH 加扰 + QPSK

sym = nrPBCH(cw,ncellid,v)
sym = nrPBCH(cw,ncellid,v,'OutputDataType',datatype)
% cw: E=864 BCH 码字；v: SSB index 低位（L=4→0..3；L=8/64→0..7）
% 输出 432 个 QPSK 符号

nrDCIEncode CRC⊕RNTI + Polar + RM

[dcicw,mcrc] = nrDCIEncode(dcibits,rnti,E)
% dcibits: DCI 消息比特；rnti: 0..65535（SI-RNTI=65535）

3三条编码链 · 接口对照

PBCH
trblk → nrBCH(CRC+Polar+RM) → cdblk[864] → nrPBCH(加扰+QPSK) → 432 sym
PDCCH
dcibits → nrDCIEncode(CRC⊕RNTI+Polar+RM) → dcicw[E] → nrPDCCH(加扰+QPSK) → E/2 sym
PDSCH
TB → CRC+LDPC+RM(nrLDPCEncode/nrRateMatchLDPC) → cws[G] → nrPDSCH(加扰+调制+层映射)

信道码PolarPolarLDPC
速率匹配→864→E→G
