# 计划：2026 Q4 双主线学习 —— O-DU/L1 协议 + RFIC（AD9361）使用

## 目标

**一句话**：用约 8 周、每天半天（约 4 h）的强度，把「O-DU/L1 协议实现」与「RFIC（以 AD9361 为主线）的驱动使用 / 射频配置」两条主线同时推进到可展示、可面试、可服务当前 Radio 软件工作的水平。

**服务的职业方向**（结合简历）：

1. **O-DU / L1 协议栈**——从现有 O-RAN AAU / M-plane / CUS-plane 经验，向 DU 侧 PHY 与调度实现拓宽；
2. **RFIC 使用（嵌入式 Linux 侧）**——不以「通用内核机制」为主线，而是把 Linux 侧学成 **会配置、会调参、会收数、会联调 RFIC**：IIO/libiio 控制面、频率/增益/带宽/ENSM/校准、DMA 数据面只学到「能解释样本从哪来」。

> 2026-09-17 调整：
> 1. 主线 B 从「Linux 内核阶段 2–8 + RTOS」收敛为 **「RFIC 使用」为主、RTOS 为辅**；u-boot/FIT、通用设备模型深读、QEMU 通用调试等不再作为闸门。
> 2. **Linux 通用内核机制已拆出为独立计划**：[[计划-独立线-Linux通用内核机制]]（G1–G5 / K1–K6），**不在本八周窗口内**；本计划不再「顺带学机制」，机制问题按需回查 [[学习-Linux-学习路线]]，不计进度。

**成功标准（8 周结束时）**：

- [ ] 能不看笔记画出「SSB → PDCCH/DCI → PDSCH/PUSCH → HARQ」的 L1 主链，并标注规范章节；
- [ ] 能指着 srsRAN 代码讲清 DU-Low / upper-PHY / OFH(7.2x) 数据通路，与自己做的 AAU CUS-plane 对照；
- [ ] **RFIC 线**：能对着 AD9361-phy sysfs / libiio / UG-570，独立完成「设 LO → 设带宽/采样 → 选增益模式 → 触发校准 → 解释 ENSM」一套操作，并画出控制面/数据面分工图；
- [ ] 能把 RFIC 参数（采样率、增益、带宽、TDD ENSM）与 L1/O-RAN 侧概念（numerology、PSD、Section Type、EVM 测试点）对上号；
- [ ] RTOS 完成阶段 0–2（任务调度 + 队列/信号量），并产出「Linux vs RTOS 数据到达路径」对照图（时间不够时可降为阶段 0–1）；
- [ ] 每条主线至少 1 篇综述笔记 + 若干概念/学习笔记，全部挂回对应 MOC。
