## 1 系统架构

平台以 Zynq UltraScale+ RFSoC（XCZU67DR）为核心，分为射频、DFE、前传、控制四层：

```text
天线 / RF 前端
   │
RFDC：8×2.95 GSPS + 2×5.9 GSPS RF-ADC，8×10 GSPS RF-DAC
   │  AXI4-Stream
DFE 硬核：DUC/DDC + Mixer(NCO) → CFR/通道滤波 → FFT/iFFT → PRACH/OFDM
   │
O-RAN Radio Interface（PG370）：eCPRI / CUS-Plane → 前传
   │
─────────────────────────────────────────────
控制面：APU 四核 A53 跑 PetaLinux
  · M-plane：NETCONF/YANG（oran-yang）
  · 载波控制 / DFE 配置：C++ + gRPC
  · 驱动：xrfdc、dfemix、dfeccf、dfeofdm、dfeprach
启动链：FSBL + PMU FW + bitstream + BL31 + U-Boot + Linux
时钟：Si5381 + 8A340001（PTP/1588），SYSREF 做 MTS 多 tile 对齐
实时面（可选）：RPU（Cortex-R5F）/ PL 逻辑
```

关键数据流：**RF-ADC → DDC/抽取 → DFE 处理 → eCPRI 前传**；下行反向。TRD 配置下 DFE DUC/DDC 接口 491.52 MSPS、DPD 采样率 983.04 MSPS、载波级 122.88 MSPS。

## 2 主要工作

- **BSP 与启动链**：基于 PetaLinux 维护 BSP，管理 FSBL/PMU/ATF/U-Boot/设备树，使用 bootgen 打包 BOOT.BIN，完成 PL bitstream 与 Linux 的联合启动与版本切换。
- **RFDC 驱动集成**：基于 xrfdc 完成 RF-ADC/RF-DAC 的采样率、抽取/内插、NCO 频点、Nyquist 区与通道使能配置；处理 PLL 锁定、时钟分发与多 tile 同步（SYSREF/MTS）。
- **DFE 链路驱动**：集成 dfemix（DUC/DDC + 混频）、dfeccf（通道滤波）、dfeofdm（FFT/iFFT）、dfeprach 驱动，打通 "RF-ADC → DFE → 前传" 全链路，定位符号定时、频偏与幅度异常。
- **OFDM / Mixer 联调**：配置 OFDM 参考链路的 CP、FFT 点数与采样率映射；完成多载波场景下的 NCO 搬移与通道滤波参数下发。
- **O-RAN 接口**：对接 M-plane（NETCONF/YANG、oran-yang 模型）完成 O-RU 配置管理与告警上报；联调 eCPRI/PG370 前传接口。
- **radio 控制框架**：参与 C++/CMake/gRPC 控制软件开发（载波控制、DFE 参数下发、故障监控、日志），支持配置文件驱动的多载波管理。
- **时钟与同步**：配置 Si5381 / 8A340001 时钟芯片，配合 PTP/1588 与 SYSREF 完成射频与前传时钟对齐。
- **调试手段**：寄存器 dump、I2C/SPI 访问、抓包分析、吞吐/时延测试，形成问题定位流程。

## 3 AGC / DPD 实时控制（二选一）

### 3.1 只做到配置与联调

> 参与 DPD/CFR 链路联调：配置 DFE DPD 硬核与观测接收通道，配合 CFR 完成 ACLR/EVM 指标验证；参与 AGC 增益表标定与 TDD 时隙内增益切换验证。

### 3.2 真正在 RPU / PL 上实现（做完再启用）

> 在 RPU（Cortex-R5F + FreeRTOS）上实现 AGC 闭环：基于 RFDC 信号检测/阈值中断计算增益，经 DSA/外部衰减器调整，加入迟滞与防抖，并与 TDD 收发时隙同步；实测收敛时间 [xx] µs、稳态误差 ±[x] dB。

> 基于 DFE DPD 硬核实现实时预失真控制：观测通道采集 PA 输出 → 计算/更新预失真系数 → 双缓冲写回，配合 CFR 降低 PAPR；在 [xx] MHz 带宽下 ACLR 改善 [x] dB。

实现要点：

- **AGC**：功率检测（RFDC threshold / signal detector 或 PL 功率估计）→ 环路滤波 → `XRFdc_SetDSA`（Gen3/DFE 数字步进衰减）或外部衰减器；只在 RX 时隙更新，避免打断 TX。
- **DPD**：DFE 硬核 + Obs RX 通道，系数更新走 DMA/共享内存，注意与 TDD 时序、CFR 前级配合；以 ACLR/EVM 验证，而不是看星座图。

## 使用说明（投递时不要带上）

1. **不要写 PRU**：Zynq 没有 PRU（那是 TI Sitara/AM 系列的外设）。ZCU670 上对应的是 **RPU（Cortex-R5F）** 或 **PL 逻辑**；写错会被直接判定为"没做过"。
2. **AGC/DPD 不要编造**：面试官会问环路带宽、收敛判据、寄存器、时延预算。只写你实际做过的层级（配置/联调/实现），并准备好对应的量化数据。
3. 时间、团队规模、量化指标（µs、dB、MHz）一律替换为真实值，`[ ]` 保留会被看出来。
