# 领域：L1 物理层

> 长期维护的领域页。收集 5G/6G 物理层知识、标准条文、算法与实现经验。

## 收集范围（待逐步充实）

## 规范速查

官方规范（R19 PDF 已入库，学习地图与下载入口见 [[3GPP-38系列-NR物理层规范]]）：

- 3GPP TS 38.211（物理信道与调制）—— 帧结构 / 参数集 / 资源网格在 §4，上下行信道与参考信号处理在 §6/§7
- 3GPP TS 38.212（信道编码与复用）—— LDPC / Polar 编码器在 §5，分信道应用在 §6（UL-SCH/UCI）与 §7（DL-SCH/PBCH/DCI）
- 3GPP TS 38.213（物理层过程-控制）—— 小区搜索 §4、HARQ-ACK §9、PDCCH 监测 §10、Type0-PDCCH §13
- 3GPP TS 38.214（物理层过程-数据）—— PDSCH §5（含 CSI §5.2）、PUSCH §6
- 配套：38.201（L1 导读）、38.215（L1 测量）、38.104（FR1/FR2 频段与带宽）
