# MOC：FPGA

FPGA 设计在通信（尤其是 L1 物理层）中的应用地图。

## 基础知识

- 时序与资源：时钟域、时序收敛、资源估算
- 语言：Verilog / SystemVerilog / VHDL
- 调试与验证：仿真、片上逻辑分析、UVM 基础

## 通信基带应用

- 数字中频：DDC / DUC、滤波
- 信号处理：FFT、FIR、同步、信道估计
- 信道编解码：LDPC / Polar / Turbo
- 高速接口：AXI、PCIe、以太网、JESD204B

## 工具链

- Xilinx Vivado / Vitis
- Intel Quartus
- 开放工具链（如开源仿真/综合工具）
