# 3GPP 38 系列规范收集：NR 物理层学习计划

## 一句话总结

按「5G NR L1 学习框架（一个核心思想 / 两大关键技术 / 三类物理信道 / 四大参考信号 / 五步处理流程，7 个学习阶段）」整理的 3GPP 官方资料：R19 最新 PDF 已入库 `90-Attachments/3GPP规范/`，本笔记提供「版本清单 + 各规范章节速查 + 学习阶段映射」。

## 版本状态（截至 2026-09-04）

- 3GPP R19 已于 2025-12（TSG#106）冻结，R20 工作已启动；38 系列现行发布版为 v19.x，本次全部下载 R19 最新 ETSI 出版版。
- 基础概念（帧结构、信道处理链、编码框架）从 R15 到 R19 基本一致；R17/R18 后主要是特性增量，不会改动骨架，但小节号会有增删，阅读时以 PDF 目录为准。
- 若对照 srsRAN / OAI 等开源代码学习，注意开源实现多以 R15–R17 特性为主（部分 R18），配置参数可能比 R19 少；确有需要时可再补同版本 R17/R18 PDF 对比。

## 各规范怎么读（章节速查）

### 38.211 —— 帧结构 + 上下行信道与信号（学习量最大）

- §4 帧结构与物理资源 —— 阶段 1 主读（R19 v19.4.0 小节拆分）：
  - 4.1 General：时间单位 T_c / T_s、κ 的定义（见 [[概念-NR时间单位-Tc与Ts]]）
  - 4.2 Numerologies：Δf = 15×2^μ kHz 与 CP（Table 4.2-1）
  - 4.3 Frame structure：4.3.1 帧 / 半帧 / 子帧、4.3.2 时隙（Table 4.3.2-1/-2：符号数、时隙数）
  - 4.4 Physical resources：4.4.1 天线端口与 QCL、4.4.2 资源网格、4.4.3 资源元素 RE、4.4.4 资源块（Point A / CRB / PRB / VRB / 交织 RB）、4.4.5 BWP、4.4.6 MBS 公共频域资源
  - 4.5 Carrier aggregation（阶段 1 只需知道存在，细节后续再展开）
- §5：通用功能 —— 调制映射、序列生成、OFDM 基带信号生成、调制与上变频（2026-09-08 已初读，见 [[学习-38.211-第5章-通用功能]]）
- §6 上行：6.3.1 PUSCH、6.3.2 PUCCH、6.3.3 PRACH 的处理链（加扰 → 调制 → 层映射 → 预编码 → RE 映射）；6.4.1 上行参考信号（PUSCH/PUCCH 的 DMRS、PT-RS、SRS）
- §7 下行：7.3.1 PDSCH、7.3.2 PDCCH、7.3.3 PBCH 的处理链；7.4.1 下行参考信号（7.4.1.1 PDSCH DMRS、7.4.1.2 PT-RS、7.4.1.3 PDCCH DMRS、7.4.1.4 PBCH DMRS、7.4.1.5 CSI-RS）；7.4.3 SS/PBCH block（含 PSS / SSS / PBCH DMRS 映射）

### 38.212 —— 编码与复用

- §4：传输信道 → 物理信道映射（UL-SCH→PUSCH、DL-SCH→PDSCH、BCH→PBCH、DCI→PDCCH、UCI→PUCCH/PUSCH）
- §5：通用编码过程 —— CRC、Polar 与 LDPC 编码、速率匹配、交织（LDPC 基图 BG1/BG2 在此）
- §6 上行：6.1 RACH、6.2 UL-SCH（6.2.4 信道编码）、6.3 UCI（6.3.1.3 信道编码）
- §7 下行：7.1 BCH/PBCH（7.1.1 载荷生成、7.1.4 信道编码）、7.2 DL-SCH（含 7.2.4）、7.3 DCI（含 7.3.3）

### 38.213 —— 控制相关过程

- §4：小区搜索（含 MIB → Type0-PDCCH CSS → SIB1 的时机判断）
- §7：上行功率控制（PUSCH / PUCCH / SRS / PRACH）
- §9：控制信息上报（HARQ-ACK 码本与 PUCCH 时序）
- §10：UE 确定 PDCCH 监测（CORESET、搜索空间、监测时机 / BD / CCE 预算）
- §13：Type0-PDCCH CSS 监测（SIB1 相关表格）

### 38.214 —— 数据相关过程

- §5：PDSCH 相关过程 —— 5.1 接收流程（时频分配、MCS/TBS、DMRS、CBG、TCI/QCL），5.2 CSI 测量与上报框架
- §6：PUSCH 相关过程 —— 6.1 发送流程（时频分配、k2、RV、跳频等）

### 38.215 / 38.104 / 38.300 / 38.321 / 38.331

- 38.215：SS-RSRP、CSI-RSRP 等 L1 测量定义（很短，波束管理时查）
- 38.104：FR1/FR2 频段与信道带宽（阶段 1 讲「频带划分」时查）
- 38.300：整体架构与协议栈分工（阶段 0 背景）
- 38.321：MAC 层 HARQ / 调度 / RACH（阶段 7 配合）
- 38.331：MIB / SIB1 及 RRC 配置结构（阶段 2「读 MIB/SIB1」时配合）

## 与原学习计划的勘误

- 计划写「LDPC = TS 38.212 第 5 章、Polar = TS 38.212 第 6 章」不准确：Polar 与 LDPC 的编码器定义都在 38.212 第 5 章；分信道应用在第 6 章（UL-SCH 用 LDPC、UCI 用 Polar）和第 7 章（DL-SCH 用 LDPC；BCH/PBCH、DCI/PDCCH 用 Polar）。
- 计划写 SSB / CSI-RS 在 38.211「第 7.4 章」偏粗：SS/PBCH block 在 §7.4.3，CSI-RS 在 §7.4.1.5，DMRS 按信道分 §7.4.1.1 / 7.4.1.3 / 7.4.1.4。
- 计划对 38.213 的引用基本正确（§4 小区搜索、§9 HARQ-ACK、§10 PDCCH），SIB1 的 Type0-PDCCH CSS 表格可再翻 §13。
- 阶段 1 的 R15-era 编号（4.1 帧结构 / 4.2 参数集 / 4.3 资源网格）与 R19 不同：v19.4.0 为 4.1 General、4.2 Numerologies、4.3 Frame structure（4.3.1 帧/子帧、4.3.2 时隙）、4.4 Physical resources（资源网格在 4.4.2）。阅读时以 PDF 目录为准。
