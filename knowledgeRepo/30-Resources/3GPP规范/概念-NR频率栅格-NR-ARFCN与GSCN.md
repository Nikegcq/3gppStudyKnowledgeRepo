# 概念：NR 频率栅格 —— NR-ARFCN 与 GSCN 是怎么来的

## 一句话

“频率栅格”不是从某个物理量推导出来的，而是 **3GPP 在规范里直接定义的离散频点集合**：先用**公式**把“频点 ↔ 编号”（NR-ARFCN / GSCN）互相换算，再用**查表**限定每个频段实际允许用哪些编号。为什么步长是 5/15/60 kHz、1.2/1.44/17.28 MHz，背后是“和 LTE 兼容、和子载波网格对齐、以及 UE 盲搜不能太慢”三件事。

## 先分清三套“栅格”

| 名称 | 作用 | 编号 | 颗粒度（FR1） | 定义处 |
| --- | --- | --- | --- | --- |
| 全局频率栅格（global raster） | 定义所有 RF 参考频率 F_REF 的集合 | NR-ARFCN（N_REF） | 5 kHz（<3 GHz）、15 kHz（3–24.25 GHz） | TS 38.101-1 §5.4.2.1 |
| 信道栅格（channel raster） | 每个 operating band 内**允许用作载波中心**的频点子集 | 复用 NR-ARFCN | 100 kHz 或 15/30 kHz（看频段） | TS 38.101-1 §5.4.2.3 |
| 同步栅格（sync raster） | UE 无先验信息时**盲搜 SSB** 的候选频点 | GSCN（SS_REF） | 约 1.2 MHz / 1.44 MHz 一个候选 | TS 38.101-1 §5.4.3.1 |

一句话记忆：**NR-ARFCN 告诉网络和 UE“载波频道放哪”，GSCN 告诉 UE“去哪里找 SSB”**。二者都落在全局栅格上，但不是一一对应的两套编号。

## 1. 全局栅格与 NR-ARFCN：公式换算

38.101-1 Table 5.4.2.1-1 给出映射公式：

F_REF = F_REF-Offs + ΔF_Global × (N_REF − N_REF-Offs)

| 频率范围 | ΔF_Global | F_REF-Offs | N_REF-Offs | N_REF 范围 |
| --- | --- | --- | --- | --- |
| 0 – 3000 MHz | 5 kHz | 0 | 0 | 0 – 599999 |
| 3000 – 24250 MHz | 15 kHz | 3000 MHz | 600000 | 600000 – 2016666 |
| 24250 – 100000 MHz（FR2，见 38.101-2） | 60 kHz | 24250 MHz | 2016667 | 2016667 – 3279166 |

速算例子：

- 低频段（<3 GHz）**基本就是 F_REF(kHz) ÷ 5**：n1 下行 2130 MHz → N_REF = 2130 MHz / 5 kHz = 426000。
- 中频段：n78 下行 3500.01 MHz → N_REF = 600000 + (3500.01−3000) MHz / 15 kHz = 600000 + 33334 = 633334。注意 3500.00 MHz 不在 15 kHz 栅格上，所以“整数 MHz 的载波”未必合法，这也是栅格讨论容易踩的坑。

## 2. 信道栅格：全局栅格的“每频段子集”

每个 operating band 从全局栅格里取一部分频点作为合法载波位置，颗粒度 ΔF_Raster 可以等于或大于 ΔF_Global（38.101-1 §5.4.2.3）：

- **100 kHz 栅格**（低频重耕频段，承袭 LTE 信道栅格）：等于 20 × 5 kHz，表中步长记为 `<20>`。例：n1 下行 `422000 – <20> – 434000`，即 2110–2170 MHz 上每 100 kHz 一个候选。
- **15 kHz / 30 kHz 栅格**（新频段，更灵活）：15 kHz 等于 3 × 5 kHz（<3 GHz，步长 `<3>`）；≥3 GHz 直接 1 × 15 kHz（步长 `<1>`）；同时支持 30 kHz 的频段再给一行步长 `<2>` 或 `<6>`。例：n41 `499200 – <3> – 537999`（15 kHz）、`499200 – <6> – 537996`（30 kHz）；n78 `620000 – <1> – 653333`（15 kHz）、`620000 – <2> – 653332`（30 kHz）。
- 还有两类修正：
  - **Enhanced channel raster**：部分 100 kHz 栅格频段额外提供 10 kHz 栅格（`<2>` 步长，38.101-1 Table 5.4.2.3-5），用于 n46 等共享频谱场景；
  - **7.5 kHz shift**：对 FDD 上行 / SUL 及 n34/n38/n39/n40/n48/n90 等，可配置 `frequencyShift7p5khz` 把 F_REF 再偏移 0 或 7.5 kHz（仅 15 kHz SCS 上行场景，38.101-1 §5.4.2.1）。

载波频点 F_REF 落到资源网格哪个 RE 也有规定（Table 5.4.2.2-1）：总 RB 数 N_RB 为偶数时对应中心 RB 的 k=0，奇数时对应 k=6——所以**“载波中心”不一定等于某个子载波中心**。

## 3. 同步栅格与 GSCN：给 UE 盲搜用的粗栅格

38.101-1 §5.4.3.1 原文：同步栅格表示“没有显式信令告知 SSB 位置时，UE 可用于系统获取的 SSB 频点集合”。它故意比信道栅格粗很多：

Table 5.4.3.1-1（>3 MHz 信道带宽的全局同步栅格）：

| 频率范围 | SS_REF 公式 | GSCN | GSCN 范围 |
| --- | --- | --- | --- |
| 0 – 3000 MHz | N × 1200 kHz + M × 50 kHz（N=1..2499，M∈{1,3,5}） | 3N + (M−3)/2 | 2 – 7498 |
| 3000 – 24250 MHz | 3000 MHz + N × 1.44 MHz（N=0..14756） | 7499 + N | 7499 – 22255 |
| 24250 – 100000 MHz（FR2，38.101-2） | 24250.08 MHz + N × 17.28 MHz（N=0..4383） | 22256 + N | 22256 – 26639 |

解读低频段的公式：以 **1.2 MHz 为周期**，每个周期内 M 可取 1/3/5（偏移 50/150/250 kHz），即 GSCN 每 3 个号对应 1.2 MHz；只支持 SCS 对齐栅格的频段默认 M=3（注 1）。3 MHz 窄带（eRedCap）另有独立栅格（Table 5.4.3.1-2），n100 还有两个特例 GSCN。

SS_REF 与 SSB 的关系（§5.4.3.2）：同步栅格频点对应 SSB 内部 **RE k=120**，不是 SSB 左边缘，也不是载波中心——所以拿到 SSB 后还要靠 MIB 里的 k_SSB / offsetToPointA 才能把 SSB 对齐到 CRB/Point A 网格。

## 4. 每个频段只允许一部分 GSCN（关键一步）

全局公式算出的 GSCN 只是“理论上存在”，具体频段还要查 Table 5.4.3.3-1，它会同时限定 **SSB SCS、SSB pattern（Case A/B/C…）和 GSCN 范围与步长**：

| 频段 | SSB SCS | Pattern | 允许的 GSCN |
| --- | --- | --- | --- |
| n1（2110–2170 MHz DL） | 15 kHz | Case A | 5279 – `<1>` – 5419 |
| n78（3300–3800 MHz） | 30 kHz | Case C | 7711 – `<1>` – 8051 |
| n79 | 30 kHz | Case C | ≥40 MHz：8480 – `<16>` – 8880；<40 MHz：8475 – `<1>` – 8884 |
| n258（FR2，38.101-2） | 120/240 kHz | Case D/E | 22257 – `<1>` – 22443 / 22258 – `<2>` – 22442 |

## 5. 算例（正算 + 反算）

**GSCN → SS_REF（>3 GHz）**：n78 中 GSCN 7846：N = 7846 − 7499 = 347 → SS_REF = 3000 + 347 × 1.44 = **3499.68 MHz**。

**GSCN → SS_REF（<3 GHz）**：n1 中 GSCN 5279：3N + (M−3)/2 = 5279，取 N=1760、M=1 → SS_REF = 1760 × 1.2 + 0.05 = **2112.05 MHz**（2110–2170 MHz 内第一个合法 SSB 位置）。

**反算（部署时挑频点）**：目标 SS_REF = 3499.68 MHz → N = (3499.68 − 3000) / 1.44 = 347 → GSCN = 7499 + 347 = 7846；如果目标频率不是整数个 1.44 MHz，就取“落在本频段允许表里、离目标最近”的 GSCN。低频段更麻烦一点：先按 1.2 MHz 取 N，再在 M∈{1,3,5} 里选最接近的偏移。

## 6. 这些步长“为什么是这些数”

1. **全局栅格 5 kHz（<3 GHz）**：5 = gcd(15 kHz 的 NR SCS 网格, 100 kHz 的 LTE/旧系统信道栅格)，也整除 GSM 的 200 kHz。低频要和 LTE 共站/共址，需要能找到“同时落在 15 kHz 子载波网格和 100 kHz 频道栅格上”的中心频点。
2. **3–24.25 GHz 用 15 kHz**：没有 LTE 低频遗留约束，直接取与 SCS 相同的颗粒度，子载波天然对齐；**FR2 用 60 kHz**：与 120/240 kHz SCS 成倍数，保证子载波对齐（38.101-2）。
3. **信道栅格每频段可再放宽**：重耕频段沿用 100 kHz 与 LTE 频道一一对齐；新频段（n41/n77/n78/n79 等）用 15/30 kHz 获得更多摆放自由度。
4. **同步栅格必须粗**：UE 开机盲搜的候选数 ≈ 频带宽度 ÷ 同步步长。n78 全带只允许 7711–8051 约 **341 个 GSCN**；若按 15 kHz 信道栅格扫，同样 500 MHz 要扫 3 万多个位置。同步步长（≤1.44 MHz）远小于 SSB 带宽（30 kHz SCS 时 7.2 MHz），所以任意合法载波位置都能保证被某个候选 GSCN“罩住”。
5. **GSCN 与载波中心解耦**：SSB 不要求在载波中心，甚至不需要落在本信道的栅格点上；UE 找到 SSB 后再读 PBCH/MIB 里的 k_SSB、offsetToPointA 等字段回推 Point A（接 [[学习-38.211-阶段1-帧结构与时频资源]]）。
