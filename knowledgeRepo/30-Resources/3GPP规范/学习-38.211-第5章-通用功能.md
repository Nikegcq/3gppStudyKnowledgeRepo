# 学习：38.211 第 5 章 —— 通用功能（调制 / 序列 / OFDM 基带 / 上变频）

## 一句话

第 5 章是 38.211 的“工具箱”：把比特变成调制符号（§5.1）、生成各类序列（伪随机与低 PAPR，§5.2）、把 RE 网格上的复符号合成带 CP 的 OFDM 时域信号（§5.3）、再上变频到载波（§5.4）。第 6/7 章所有信道的处理链都会调用这些通用功能。

## 章节结构与定位

| 小节 | 内容 | 学习定位 |
| --- | --- | --- |
| 5.1 Modulation mapper | π/2-BPSK、BPSK、QPSK、16/64/256/1024QAM 的比特→符号映射 | 必读，建立星座图直觉 |
| 5.2 Sequence generation | 5.2.1 伪随机（Gold）序列；5.2.2/5.2.3 低 PAPR 序列 type 1 / type 2 | 先懂“两种序列家族”和用途，查表细节用时再翻 |
| 5.3 OFDM baseband signal generation | 5.3.1 除 PRACH/RIM-RS 外的 OFDM 基带信号；5.3.2 PRACH；5.3.3 RIM-RS | 5.3.1 必读（CP 长度公式）；后两节知道存在即可 |
| 5.4 Modulation and upconversion | 基带信号上变频到载波频率 f0 | 概念性了解 |

注意：R19 把 §5.2 叫 Sequence generation；加扰本身按信道定义在第 6/7 章（PUSCH/PDSCH/PDCCH 等各自的 scrambling 小节），但它依赖 §5.2.1 的伪随机序列生成器。

## 5.1 调制映射（§5.1）

输入比特 b，输出复符号 d(i)。R19 支持 7 种调制（1024QAM 是最新的）：

| 调制 | 比特/符号 | 归一化系数 | 备注 |
| --- | ---: | --- | --- |
| π/2-BPSK | 1 | 1/√2（每符号再旋 π/2） | 低 PAPR 场景（PUCCH/PUSCH 相关格式） |
| BPSK | 1 | 1/√2 | 较少见，特定场景 |
| QPSK | 2 | 1/√2 | 最常见，最稳健 |
| 16QAM | 4 | 1/√10 | |
| 64QAM | 6 | 1/√42 | |
| 256QAM | 8 | 1/√170 | |
| 1024QAM | 10 | 1/√682 | 高频谱效率，信道条件要求高 |

QPSK 示例（I/Q 独立、Gray 编码）：d(i) = (1/√2)·[(1−2b(2i)) + j(1−2b(2i+1))]。归一化系数保证各调制平均功率相同，接收机只看相对星座点位置。

## 5.2 序列生成（§5.2）

### 5.2.1 伪随机序列（Gold 序列）

- 两个长度 31 的 m 序列按位异或合成，N_c = 1600 个初始偏移。
- c_init 是第二个 m 序列的初始化值（≤31 bit），由使用场景决定（加扰、参考信号等各给各的 c_init 公式）。
- 典型用途：数据/控制信道的加扰序列、CSI-RS 等伪随机序列——第 6/7 章各信道小节会给 c_init 的具体定义。

### 5.2.2 低 PAPR 序列 type 1

- 基础序列来自 ZC（Zadoff-Chu）或查表 φ(n)，再乘循环移位 e^{jαn} 得到 r_u,v^(α,δ)。
- 序列长度 M_ZC：≥36 用 ZC 公式；6/12/18/24/30 用规范表格（Table 5.2.2.2-x）。
- 典型用途：DM-RS、SRS、PUCCH 等参考信号序列（低 PAPR 对 UE 功放友好）。

### 5.2.3 低 PAPR 序列 type 2

- 另一族低 PAPR 序列，短长度（6/12/18/24 等）由 π/2-BPSK 调制伪随机二进制序列得到，也有查表。
- 具体哪些信道用 type 1 / type 2，读 DM-RS / SRS / PUCCH 小节时对照即可。

## 5.3 OFDM 基带信号生成（§5.3）

### 5.3.1 通用公式（除 PRACH / RIM-RS）

思路：RE 网格上的复符号 a_{k,l}^(p,μ) 就是各子载波上的“权重”，IFFT 前每个子载波 e^{j2π k Δf t}，再加 CP、拼接成符号流：

- 符号长度：T_symb = (N_u^μ + N_CP,l^μ)·T_c
- 符号有效部分长度：N_u^μ = 2048·κ·2^{−μ}（κ=64）
  - 注意：N_u^μ 是“以基本时间单位 T_c 计的样本数”，等价于时长 1/Δf，不是实现里的 IFFT 点数。例如 μ=0 时 N_u = 2048·64 = 131072 个 T_c 样本，正好等于 2048 个 T_s（LTE 采样周期）样本 = 66.67 μs。
  - 真实实现的 FFT 大小按“覆盖子载波数”取 2 的幂（如 2048/4096/8192…），采样率 = Δf × FFT 大小；131072 点是拿 1/T_c ≈ 1.966 GHz 的“母钟”去数一个符号才得到的数。
- CP 长度（样本数）：
  - Normal：N_CP,l^μ = 144·κ·2^{−μ}，若 l=0 或 l=7·2^μ（子帧内符号序号）再加 16·κ；
  - Extended（仅 μ=2）：N_CP,l^μ = 512·κ·2^{−μ}
- 符号起点递推：t_start,l = t_start,l−1 + (N_u + N_CP,l−1)·T_c，子帧起点 t=0。
- k0 的作用：把当前 μ 的网格中心对齐到“参考 numerology”的载波中心（不同 SCS 频谱中心一致），公式里用 N_grid,start/size 与最大 μ 的 scs-SpecificCarrierList 换算。
- 频谱搬移：k 轴上减去 N_grid,size·N_sc^RB/2，相当于把频带中心放到本地振荡器（DC）位置，再让负半轴可表达低频。

上行还有 cyclic prefix extension：PUSCH/SRS/PUCCH 等首个符号可在前面把 CP 再延长一段（Table 5.3.1-1/-2/-3 给配置值），用于配合定时提前等场景；细节用时再读。

### 5.3.2 PRACH

- PRACH preamble 有自己的时域生成公式（ZC 序列、独立 CP 长度 N_CP^RA）。
- SCS 覆盖 1.25/5/15/30/60/120/480/960 kHz 等（1.25/5 kHz 是长前导格式专属，不在 numerology 表内）；具体序列/格式在 §6.3.3。

### 5.3.3 RIM-RS

- 较新引入的测量参考信号（Δf = 15/30 kHz），结构类似通用 OFDM；学习主线可先跳过，遇到再回看。

## 5.4 调制与上变频（§5.4）

- 把 §5.3 生成的复基带信号搬上射频：取实部 Re{基带 × e^{j2π f0 t}}（PRACH/RIM-RS 有各自细节）。
- 上行规范允许 UE 按实现加滤波以满足 38.101 系列的频谱要求（规范里的 NOTE）。

## 与第 4 章及后续章节的关系

- 第 4 章定义了 RE 坐标与资源网格；第 5 章把这些“格子”变成真实可发射的波形。
- 各信道处理链（§6 上行 / §7 下行）的顺序大致是：加扰（用 §5.2.1 序列）→ 调制（§5.1）→ 层映射/预编码 → RE 映射 → §5.3 生成 OFDM → §5.4 上变频。
- DFT-s-OFDM（transform precoding）的上行低 PAPR 波形在对应上行信道章节（PUSCH 等）另行定义，第 5 章给的是 CP-OFDM 这条主线。

## 练习（可选）

1. 手算 4 个 QPSK 符号（00/01/10/11）的复数值，画星座图并验证归一化功率为 1。
2. 用 μ=0、Normal CP 算一个符号的总样本数：N_u=2048·64，CP=144·64（首符号/第 7 符号 +16·64），验证 14 个符号恰好凑成 1 ms 时隙。
3. 对照 srsRAN 代码里的调制映射 / OFDM 调制实现，找到“IFFT 大小与 CP 长度”对应 5.3.1 公式的位置（见 [[仓库-srsRAN_Project-下行物理信道与OFDM发射]]）。

## FAQ：RB 数（如 273）和 CP / IFFT 有什么关系？

没有直接关系。“100 MHz、30 kHz → 273 RB”来自 38.104 Table 5.3.2-1（FR1 的传输带宽配置表），是网络选定的“这个信道带宽下最多放多少 RB”，不是从 CP 或 IFFT 算出来的。

- 验证：273 RB × 12 子载波 × 30 kHz = 98.28 MHz；100 MHz 减去 98.28 MHz 后两侧留保护带（该配置单侧最小保护带 845 kHz，约 1.69 MHz 合计），正好装进 100 MHz 信道。
- 275 是系统上限（maxNrofPhysicalResourceBlocks，见 38.300/38.331），实际查表值 ≤ 275；若放 275 RB 则 99 MHz + 保护带超过 100 MHz，放不下。
- 接收端去掉 CP 后做 FFT，覆盖的是“配置的整个载波网格”：273 RB = 3276 个有效子载波，FFT 取下一个 2 的幂 4096 点，多出的 bin 补零当保护。RB 数在发射/接收两侧都是一样的。
