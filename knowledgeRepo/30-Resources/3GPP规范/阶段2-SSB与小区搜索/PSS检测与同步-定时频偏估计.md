# PSS 检测与同步：定时、频偏是怎么算出来的

## 一句话

规范只规定“PSS 是 127 长的已知序列、放在 SSB 第 0 个符号的中间 127 个子载波上”；怎么从接收信号里找到它、算出符号起点和载波频偏，属于接收机实现（DSP 算法），不在规范里写死。典型做法是：用已知 PSS 做相关找峰值（定时 + N_ID^(2)），再用 CP 自相关估小数倍频偏、FFT 后子载波平移搜索估整数倍频偏，最后用 SSS/PBCH DM-RS 细化。

## 先分清：哪些是规范定的，哪些是实现定的

- 规范（38.211 §7.4.2/§7.4.3）定：PSS 序列（3 条）、长度 127、映射到 SSB 符号 0 的 k=56..182、SSB 共 4 个符号、SSB 在时隙里的候选位置由 Case 决定（38.213 §4.1）。
- 实现定：检测算法、相关窗长、门限、频偏搜索范围、跟踪环——只要满足 38.101/38.133 的灵敏度、检测时间等要求即可。
- 所以下面所有“算法”都是典型接收机做法，不是唯一答案。

## 接收信号模型（简化）

把接收到的 PSS 符号（去 CP 前后）看成：

r(n) = h · p(n) · e^(j2π·ε·n/N_u) + w(n)

- p(n)：本地已知的 PSS 时域序列（对应该 N_ID^(2) 与假定的 SSB SCS）；
- ε = Δf / Δf_SCS：载波频偏（CFO）除以子载波间隔的“归一化频偏”；
- N_u：一个有用符号的采样数；
- w(n)：噪声/干扰。

频偏会让序列整体旋转：ε 的整数部分把子载波“平移整数格”，小数部分让所有子载波旋转同一个相位斜率。所以估频偏通常拆成“小数倍”和“整数倍”两步。

## Step A：粗定时——用 PSS 相关峰

UE 不知道符号起点，所以对接收信号做**滑窗相关**：在每个候选时刻 t，把接收窗与本地 PSS 模板相关，找峰值：

- 3 条 PSS（N_ID^(2)=0/1/2）各做一路相关，峰值最大的一路同时给出 N_ID^(2) 和 PSS 符号起点；
- 相关峰位置 ≈ SSB 符号 0 的起点 → **OFDM 符号定时**；
- 若同时搜索多个 SSB SCS/时隙假设（如 FR1 的 15/30 kHz），就多套模板各做一遍。

抗频偏的常见技巧：长序列全相干相关会被频偏旋转破坏，所以把 127 点分成若干小段，**每段相干、段间非相干**合并（取每段相关的幅值再相加），峰值在残余频偏下仍然明显。

## Step B：小数倍频偏——用 CP 或跨符号相位差

OFDM 符号的 CP 是符号末尾一段的复制，频偏会让“CP 段”和“对应末尾段”之间产生固定相位差：

Δf̂ = arg( Σ_n r*(n) · r(n + N_u) ) / (2π · T_u)

- n 遍历 CP 的采样点，r(n+N_u) 是符号内与 CP 对应的“本体”部分；
- 相位差 = 2π·Δf·T_u，所以除回去就是小数倍频偏（范围约 ±0.5 个子载波间隔）；
- 有了估计就把接收信号反向旋转补偿，再做 FFT。

## Step C：整数倍频偏——FFT 后平移子载波搜索

晶振偏差在毫米波/高频段可能远大于一个 SCS（例如 3.5 GHz、±10 ppm 就约 ±35 kHz），所以还要估“整数个子载波”的偏移：

q̂ = argmax_q | Σ_k R(k + q) · P*(k) |

- R(k)：补偿小数倍频偏后、FFT 得到的频域符号；
- P(k)：本地 PSS 频域模板（127 点）；
- q：整数子载波平移，在预期范围内扫（如 ±2、±5…个 SCS）；
- 峰值对应的 q 就是整数倍频偏。

## Step D：细化与跟踪

- 已知 PCI 后，用 **SSS**（127 点、位置已知）做更准的频域相关；
- 用 **PBCH DM-RS**（跨 4 个符号、位置由 PCI mod 4 决定）做符号级相位差，细化定时与频偏；
- 进入稳态后由 AFC/定时跟踪环持续校正时钟漂移（这就是上一问里“下一个 10 ms 位置保持”的实现基础）。

## PSS 怎么给出“SSB 时间结构”

“SSB 时间结构”有两层：

1. **SSB 内部结构（立刻可得）**：PSS 找到 = 符号 0 起点。规范规定第 1 个符号是 PSS、第 2 个是 PBCH（符号 1）、第 3 个是 SSS（符号 2）、第 4 个是 PBCH（符号 3）。所以知道 PSS 位置就知道 SSS/PBCH 在接下来哪几个符号——后续 SSS 检测不需要全帧搜索，直接在“PSS 后 2 个符号”处做相关即可。
2. **SSB 在时隙/半帧里的候选位置（受 Case 约束）**：Case 规定候选 SSB 首符号只能出现在固定位置（如 Case A = {2,8}+14n、Case D = {4,8,16,20}+28n）。检测到 PSS 后，UE 就能知道“这是候选图案里的哪一个位置”，同一半帧里其它候选 SSB 的相对位置也随之可预测。

注意边界：**SSB 内部位置和 Case 位置 ≠ 帧号**。第几个候选 SSB（SSB index）要 PBCH DM-RS + PBCH 载荷，第几帧/哪个半帧要 PBCH 的 SFN 与 HRF 位。

## 常见误区

- “PSS 序列里编码了频偏/时间结构”——不对：序列只编码 N_ID^(2)；定时和频偏是相关峰/相位差**估出来**的副产品。
- “频偏一次估完”——一般分小数倍（CP/相位差）和整数倍（子载波平移搜索）两步，再细化。
- “检测算法在规范里”——不在；38.211 只定义发射端序列与映射，接收算法自由，要求见 38.133。
