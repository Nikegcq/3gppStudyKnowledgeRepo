# 概念：ADC 采样、量化与 SAR

## 一句话总结

ADC = **采样**（时间离散）→ **量化**（幅度离散）→ **编码**（格子号变成二进制码）。量化「落在哪一格」在硬件上有三种主流做法：**Flash 全并行比较**、**SAR 二分查找**、**ΔΣ 过采样 + 噪声整形**；**SAR 不是流程的第四步**，而是量化这一步的一种实现算法——1 个比较器 + 内部 DAC + 寄存器，N 个时钟定出 N-bit 码。

---

## 1. ADC 相关参数

### 1.1 基础定义参数

| 参数 | 符号 / 单位 | 含义 |
| --- | --- | --- |
| 分辨率 | $N$（bit） | 码字位数，把量程切成 $2^N$ 格 |
| 满量程范围 | FSR（V） | 能表示的模拟电压跨度，如 0–1 V、±0.5 V |
| 量化步长 / LSB | $\mathrm{LSB}=\mathrm{FSR}/2^N$（V） | 一格的电压宽度 |
| 量化格数 | $L=2^N$ | 离散电平个数 |
| 输入范围 | $V_{\min}\sim V_{\max}$ | 实际允许输入；超出会削顶/回绕 |
| 采样率 | $F_s$（sps / Hz） | 每秒采样点数（对外数据率） |
| 转换时间 | $t_c$（s） | 完成一次「模拟→码」所需时间 |
| 吞吐率 | （sps） | 连续转换时每秒能出多少码（流水线可 > $1/t_c$） |

12-bit、FSR = 1 V 时：$\mathrm{LSB}\approx 0.244\,\mathrm{mV}$，共 4096 格。

### 1.2 静态精度参数（看「格子画得准不准」）

| 参数 | 含义 | 典型问题 |
| --- | --- | --- |
| 量化误差 | 理想 $\pm\mathrm{LSB}/2$ | 与真值最近格子的偏差，均匀分布 |
| 失调误差 Offset | 整条转移曲线平移 | 0 V 输入不落在码字中心 |
| 增益误差 Gain | 曲线斜率偏差 | 满量程点对不齐 |
| **DNL** 微分非线性 | 相邻台阶宽度偏差 | 某格过宽/过窄；DNL < −1 LSB 会**丢码** |
| **INL** 积分非线性 | 转移曲线相对理想直线的偏差 | 累积弯曲，谐波失真的主因之一 |
| 单调性 | 输入增大时码不减 | 控制环路/反馈用 ADC 必须单调 |

### 1.3 动态性能参数（看「带信号时干不干净」）

| 参数 | 含义 |
| --- | --- |
| **SNR** 信噪比 | 信号功率 / 噪声功率（不含谐波时近似 SNDR） |
| **SQNR** 量化信噪比 | 只考虑量化噪声时的理论上限 |
| **THD** 总谐波失真 | 谐波功率 / 信号功率 |
| **SINAD / SNDR** | 信号 /（噪声 + 失真），工程最常用 |
| **ENOB** 有效位数 | 把 SINAD 折算成「实际相当于几 bit」 |
| **SFDR** 无杂散动态范围 | 信号 / 最大杂散（谐波或毛刺） |
| 孔径延迟 | 采样命令到真正「冻结」的延迟 |
| **孔径抖动** $\sigma_j$ | 采样时刻的随机抖动，直接吃掉高频 SNR |
| 模拟输入带宽 | 能跟上多高的输入频率（满功率带宽更严） |
| 功耗 | mW / mW·MHz，便携与 AAU 都要抠 |

### 1.4 关键公式速查

$$
\mathrm{LSB}=\frac{\mathrm{FSR}}{2^N},\qquad
\sigma_q=\frac{\mathrm{LSB}}{\sqrt{12}}
$$

$$
\mathrm{SQNR}\approx 6.02N+1.76\ \mathrm{dB}
\quad\Rightarrow\quad
+1\ \mathrm{bit}\approx +6\ \mathrm{dB}
$$

$$
\mathrm{ENOB}=\frac{\mathrm{SINAD}-1.76}{6.02}
$$

$$
\mathrm{SNR}_{\mathrm{jitter}}\approx -20\log_{10}\bigl(2\pi f_{\mathrm{in}}\sigma_j\bigr)
$$

（上式为采样钟抖动限制。）

过采样时（与 [[概念-ADC与Delta-Sigma入门]] 一致）：

$$
\mathrm{SQNR}\approx 6.02N+1.76+10\log_{10}(\mathrm{OSR}),
\qquad
\mathrm{OSR}=\frac{F_{s,\mathrm{ADC}}}{F_s}
$$

> **选型直觉**：标称 bit ≠ 有效 bit。高速、高 $f_{\mathrm{in}}$ 场景先看 **ENOB、孔径抖动、DNL/INL**，再看分辨率。

## 2. ADC 流程：采样 → 量化 → 编码

### 2.1 总流程

```text
v(t) ──► 抗混叠滤波 ──► 采样保持 ──► 量化 ──► 编码 ──► 数字码 D
 连续时间      限带        冻结电压    落在哪一格   格子号→二进制
```

| 步骤 | 输入 → 输出 | 一句话 |
| --- | --- | --- |
| （预）抗混叠 | 连续谱 → 限带谱 | 滤掉 $F_s/2$ 以上，防止混叠 |
| **采样** | $v(t) \to v[n]=v(nT_s)$ | 时间上离散；S/H 电容把电压**冻结** |
| **量化** | $v[n] \to$ 格子号 $k$ | 幅度上离散；映射到最近的量化级 |
| **编码** | $k \to$ 二进制 $D$ | 格子号变成接口上的码字 |

**关键分界**：采样解决「**何时取**」，量化解决「**取成多细**」，编码解决「**怎么写出来**」。SAR / Flash / ΔΣ 争的是**量化这一步怎么做**，不是在三步之外再加一步。

### 2.2 采样（时间离散）

- 节拍：$T_s=1/F_s$，采样钟来自 PLL 时钟树（见 [[概念-锁相环PLL与VCO]]）。
- **Nyquist**：$F_s \ge 2B$（实信号）；I/Q 复基带可 $F_s\gtrsim B$。
- **S/H（采样保持）**：开关闭合充电，断开后电容保持电压，给后续量化一段稳定窗口。
- **混叠**：$F_s/2$ 以上能量会折回带内，**采样定理是硬约束**，不是建议。
- **孔径抖动**：采样时刻不稳等效在输入上叠加噪声，$f_{\mathrm{in}}$ 越高、$\sigma_j$ 越大，SNR 掉得越狠——这也是「采样钟从 PLL 来」的原因。

### 2.3 量化（幅度离散）

把保持电压映射到 $2^N$ 个离散级：

$$
k = Q(v) = \mathrm{round}\!\left(\frac{v - V_{\min}}{\mathrm{LSB}}\right),
\quad k\in\{0,1,\dots,2^N-1\}
$$

| 规则 | 含义 | 备注 |
| --- | --- | --- |
| 就近取整（中升/中平） | 落到最近格子 | 最常见；量化误差 $\pm\mathrm{LSB}/2$ |
| 截断 / 饱和 | 向下取整或顶格钳位 | 实现简单，误差有偏 |
| 非均匀（压扩） | 小信号格子密、大信号格子疏 | 语音 μ-law / A-law；通信 ADC 多用均匀量化 |

量化噪声：理想均匀量化时近似白噪声，$\sigma_q=\mathrm{LSB}/\sqrt{12}$。

### 2.4 编码（格子号 → 码字）

| 码制 | 特点 | 常见场景 |
| --- | --- | --- |
| 偏移二进制 | 0 V 对应中码 `100…0` | 无符号单极性输入 |
| 二进制补码 | 有符号，0 = `0…0` | FPGA / 基带 IQ 处理（AD9361 数据面） |
| 格雷码 | 相邻格子只差 1 bit | 减少传输/比较毛刺 |
| 温度计码 | Flash 中间码，再编成二进制 | 见 §3.1 |

编码**不增加信息**，只是把「第 $k$ 格」写成接口约定的比特串。

### 2.5 时间线直觉

```text
采样:   ──┬─────┬─────┬─────┬──►  v[n]   （每 T_s 冻结一次）
量化:   ──┼─?─?─┼─?───┼─?─?─┼──►  k[n]   （硬件怎么定格：Flash/SAR/ΔΣ）
编码:   ──┼─1101┼─1110┼─1011┼──►  D[n]   （固定组合逻辑）
          n=0   n=1   n=2
```

SAR 的「N 拍」发生在**每一格 $v[n]$ 的量化内部**，不改变对外的 $F_s$ 节拍（采样率 = 转换节拍在 SAR 里通常一致）。

## 3. 量化的三种方式与算法

问题本质：**已知保持电压 $v$，确定格子号 $k$**。

### 3.1 Flash：全并行比较

```text
v ──► 比较器0,1,2,…,2^N-2（各对一个参考电平）
        │ │ │        │
        └─┴─┴──…─────┴──► 温度计码 ──► 优先编码器 ──► N-bit 码
```

| 项 | 内容 |
| --- | --- |
| 硬件 | $2^N-1$ 个比较器 + 电阻梯 + 编码器 |
| 延迟 | **1 拍**出码，最快 |
| 代价 | 比较器数量随 $N$ **指数爆炸**（8-bit 已要 255 个） |
| 算法 | **并行比较**（见下） |
| 场景 | 低 bit、极高采样率；也作 **ΔΣ 内部粗量化器** |

**算法（并行比较 + 温度计编码）**

```text
# 硬件一次性完成，无串行循环
for i in 0 .. 2^N-2:            # 同时！
    th[i] = 1 if v > Vref*(i+1)/2^N else 0

# 温度计码 → 二进制（优先编码 / 空泡纠错）
k = popcount(th)                # 理想温度计码中 1 的个数就是格子号
D = binary(k)
```

- 复杂度：时间 $O(1)$，硬件 $O(2^N)$。
- 温度计码可能出现**空泡**（比较器失配），编码前要做 bubble correction。

### 3.2 SAR：二分查找（逐次逼近）

```text
采样保持 ──► 比较器 ──► SAR 逻辑/寄存器
   ▲            │            │
   │            │            ▼
   │            │       内部 DAC（当前猜测电压）
   │            │            │
   └────────────┴────────────┘
```

| 项 | 内容 |
| --- | --- |
| 硬件 | **1 个**比较器 + 电容 DAC + SAR 寄存器 |
| 延迟 | **N 拍**定出 N-bit |
| 代价 | 速度中等；对 DAC 线性度敏感 |
| 算法 | **二分查找 / 逐次逼近**（见下） |
| 场景 | 10–18 bit、中速；MCU 片内 ADC、中速采集 |

**算法（二分查找）**

```text
# 目标：找最大 k，使 DAC(k) <= v  （等价于在电压轴二分）
code = 0
for bit from N-1 down to 0:     # 共 N 步
    trial = code | (1 << bit)   # 先猜这一位为 1
    if v >= DAC(trial):         # 比较器：输入 vs 猜测电压
        code = trial            # 猜大了也不怕，保留；不够则丢掉该位
    # else: 该位保持 0
return code
```

- 复杂度：时间 $O(N)$，硬件 $O(1)$。
- **对照：线性逐格搜索**（教学用，不实用）：从 0 格扫到 $2^N-1$，最坏 $2^N$ 次比较——12-bit 要上千次，所以才改成二分。
- **12-bit 示例**（输入 $\approx 0.73\,\mathrm{V}$，满量程 1.0 V）：

```text
猜 MSB   DAC=0.500 V   0.73>0.5?  → 1
猜 bit10 DAC=0.750 V   0.73<0.75? → 0
猜 bit9  DAC=0.625 V   0.73>0.625? → 1
… 重复 12 次 → 完整码字
```

本质：在电压轴上对量化格做 **二分搜索**。

### 3.3 ΔΣ：过采样 + 噪声整形

```text
v ──►(+)──► 积分器 ──► 粗量化(Flash/1-bit) ──► 高速比特流
      ▲                                        │
      └────────── 反馈 DAC ◄───────────────────┘
                         │
                         ▼ 数字抽取滤波（CIC/FIR）
                    高精度、较低速率的码
```

| 项 | 内容 |
| --- | --- |
| 硬件 | 环路（积分器 + 量化器 + 反馈 DAC）+ 抽取滤波器 |
| 思路 | 每拍只粗量，但 **OSR 极高**；噪声被推到带外 |
| 算法 | **误差反馈 + 噪声整形 + 抽取**（见下） |
| 场景 | 高 ENOB、中高带宽；**AD9361 片内 Rx ADC（三阶 CT-ΔΣ）** |

**算法（一阶误差反馈形式）**

```text
# 每个 ADC_CLK 拍执行（OSR 很高）
e = v - DAC(y_prev)             # 反馈误差
s = s + e                       # 积分（高阶则串联多个积分器）
y = 1 if s > 0 else 0           # 粗量化（1-bit 或少 bit Flash）
# 环路 NTF ≈ (1-z^{-1})^L，L 阶 → 量化噪声高通

# 抽取后：高速粗码 → 低速细码
d = decimate(lowpass(y), OSR)   # CIC + 补偿 FIR，再降采样到 F_s
```

- 复杂度：每拍 $O(1)$ 粗量，用 **时间（OSR）** 换幅度精度。
- 等效位数随 OSR 缓慢增长（每 4× OSR ≈ +6 dB / +1 bit），再叠加 $L$ 阶噪声整形后带内更干净。
- 细节（环路部件、AD9361 `0x200` 偏置、时钟三层）见 [[概念-ADC与Delta-Sigma入门]]。

### 3.4 三种算法对比

| | Flash | 线性搜索（对照） | **SAR** | **ΔΣ** |
| --- | --- | --- | --- | --- |
| 搜索策略 | 全并行 | 逐格扫 | **二分** | 不搜格子；时域过采样 |
| 时间复杂度 | $O(1)$ | $O(2^N)$ | $O(N)$ | $O(\mathrm{OSR})$ 拍出 1 码 |
| 比较器 | $2^N-1$ | 1 | **1** | 1（+环路） |
| 典型位数 | 低（≤8） | — | 10–18 | 高 ENOB |
| 速度 | 极快 | 极慢 | 中速 | 每拍粗量，输出率由抽取定 |
| 典型用途 | 高速瞬时、ΔΣ 内部 | 教学对照 | MCU / 中速采集 | 通信基带（AD9361） |

```text
Flash:  ||||||||||||||  全部比较器同时 → 1 码 / 1 拍
SAR:    比|猜|比|猜|… 共 N 次          → 1 码 / N 拍
ΔΣ:     每拍粗量，成千上万拍           → 抽取后 1 个高精度码
```

**AD9361**：主转换是 **三阶连续时间 ΔΣ**，不是 SAR；见 [[概念-ADC与Delta-Sigma入门]]。

## 5. 常见误解

| 误解 | 澄清 |
| --- | --- |
| 「SAR 是采样和量化之外的第三步」 | 否，SAR **实现**量化；流程仍是采样→量化→编码 |
| 「bit 越高一定越好」 | 还要看 ENOB、DNL/INL、孔径抖动、SFDR |
| 「AD9361 是 SAR」 | 否，是 **ΔΣ**；SAR 用于另一类中速 ADC |
| 「采样率越高越好」 | 先满足 Nyquist；过高增加功耗与接口负担，且抖动约束更紧 |
| 「量化噪声总能靠加 bit 压没」 | 线性度（INL）、时钟抖动、热噪声会先卡住 ENOB |
