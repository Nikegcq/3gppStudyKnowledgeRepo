# 概念：ADC 采样、量化与 SAR

## 一句话总结

ADC 在系统上就是 **采样（抓住某时刻电压）+ 量化（变成离散数字）**；**SAR** 不是第三步，而是量化的一种硬件实现——用 **1 个比较器 + 内部 DAC + 寄存器** 做 **二分查找**，N 个时钟定出 N-bit 码。

---

## 1. 正确的系统级理解

```text
连续电压 v(t) ──► 采样保持 ──► 量化 ──► 数字码
                  (冻结电压)   (落在哪一格)
```

| 步骤 | 含义 |
| --- | --- |
| 采样 | 取「当前」电压，通常用电容保持 |
| 量化 | 映射到离散台阶（如 12-bit → 4096 格） |

问题在于：**「比落在哪一格」在电路里怎么做？**

---

## 2. 三种「比法」

### Flash：所有刻度同时比

```text
电压 ──► 比较器0,1,2,…,2^N-1（各对一个参考）
```

- 1 拍出结果，极快  
- 比较器数量 \(2^N-1\)，高 bit 爆炸  
- 适合低 bit、高速（ΔΣ 内部粗量化）

### 一次只比一格：太慢

12-bit 最坏上千次比较，不实用。

### SAR：二分查找（主流中速高精度）

每步猜 1 bit，比较后保留或丢掉，共 **N 步**：

```text
12-bit 示例（输入 ≈ 0.73 V，满量程 1.0 V）：

猜 MSB  DAC=0.500V  0.73>0.5?  → 1
猜 bit10 DAC=0.750V  0.73<0.75? → 0
猜 bit9  DAC=0.625V  0.73>0.625? → 1
… 重复 12 次 → 完整码字
```

---

## 3. SAR 电路框图

```text
采样保持 ──► 比较器 ──► SAR 逻辑/寄存器
   ▲            │            │
   │            │            ▼
   │            │       内部 DAC（当前猜测电压）
   │            │            │
   └────────────┴────────────┘
```

| 部件 | 作用 |
| --- | --- |
| 采样保持 | 冻结输入电压 |
| 比较器 | 输入 vs 猜测 → 大/小 |
| SAR 寄存器 | 存已定 bit，决定下一猜 |
| DAC | 把猜测码变成模拟电压 |

本质：在电压轴上 **二分搜索** 量化格。

---

## 4. 与 Flash / ΔΣ 对比

| | 比较器 | 速度 | 典型位数 | 场景 |
| --- | --- | --- | --- | --- |
| Flash | \(2^N-1\) | 极快 | 低 | ΔΣ 内粗量化 |
| **SAR** | **1** | **中速（N 拍）** | **10–18 bit** | MCU、中速采集 |
| ΔΣ | 1（+环路） | 每拍粗量，超高 OSR | 高 ENOB | 通信基带（AD9361） |

AD9361：**主转换是三阶 CT-ΔΣ**，不是 SAR；见 [[概念-ADC与Delta-Sigma入门]]。

---

## 5. 时间线直觉

```text
Flash:  ||||||||||  全部比较器同时 → 1 个码 / 1 拍
SAR:    比|猜|比|猜|… 共 N 次     → 1 个码 / N 拍
ΔΣ:     每拍粗量，成千上万拍        → 抽取后 1 个高精度码
```

---

## 6. 生活类比

| 类型 | 类比 |
| --- | --- |
| 采样 | 给体重拍照 |
| 量化 | 归到整数公斤 |
| Flash | 一排秤同时看落点 |
| SAR | 一个秤 + 二分：>50？>75？… |
| ΔΣ | 极小砝码称几万次再平均 |

---

## 7. 常见误解

| 误解 | 澄清 |
| --- | --- |
| 「SAR 是采样和量化之外的第三步」 | 否，SAR **实现**量化 |
| 「bit 越高一定越好」 | 还要看 ENOB、线性、抖动（见 ADC 性能参数讨论） |
| 「AD9361 是 SAR」 | 否，是 **ΔΣ**；SAR 用于另一类中速 ADC |
