# AD9361 寄存器文档索引

## 一句话总结

AD9361 **没有**单独一本「完整 bit 级 Register Map」PDF；官方做法是：**UG-570 参考手册按功能讲寄存器行为**，**完整地址/bit 定义在 no-OS / Linux 驱动头文件里**。理解配置时两份对着看最有效。

## 怎么读（推荐路径）

1. **先看 UG-570 功能章节**（不要一上来啃全部 525 个寄存器）：
   - SPI 时序与读写格式（§ Serial Peripheral Interface，约 p.113）
   - 初始化与校准（§ Initialization and Calibration）— 看清 `0x016` 校准控制各 bit
   - ENSM 使能状态机（Enable State Machine Guide）— `0x013`–`0x015`
   - RF / BBPLL 合成器与 LO 配置
   - Rx/Tx 基带滤波器、FIR
   - AGC / 手动增益 / RSSI / Tx 衰减
2. **对照 `ad9361.h` 查地址与 bit 名**：文件里每条 `REG_xxx 0xNNN /* 注释 */` 就是一行寄存器表。
3. **对照 Linux 驱动 `ad9361.c`** 看「一次配置要写哪些寄存器」：
   - 本地已有笔记：[[学习-Linux-驱动开发-AD9361-从零到通]]、[[学习-Linux-驱动开发-AD9361-从dtsi到驱动调用流程]]
   - 板子上可用 IIO debugfs / `iio_reg` 直接读写验证。

### 校准控制速查（UG-570 Table 1）

| 校准 | 触发条件 | 完成标志 |
| --- | --- | --- |
| BBPLL VCO | BBPLL 频率变化时 | `0x5E[7]` |
| RF 合成器电荷泵 | 一次 | Rx `0x244[7]` / Tx `0x284[7]` |
| RF 合成器 VCO | 写整数频字；TDD 下 TXNRX 翻转 | Rx `0x247[1]` / Tx `0x287[1]` |
| 基带 Rx 模拟滤波 | 带宽变化 | `0x016[7]`（自清） |
| 基带 Tx 模拟滤波 | 带宽变化 | `0x016[6]`（自清） |
| 基带 DC offset | 一次 | `0x016[0]`（自清） |
| RF DC offset | LO 变化 > 100 MHz | `0x016[1]`（自清） |
| Rx 正交校准 | LO 变化 > 100 MHz | 持续跟踪 |
| Tx 正交校准 | LO 变化 > 100 MHz | `0x016[4]`（自清） |

校准序列状态在 `0x017`：`0x1` = 全部完成。

## 寄存器地址大致分区（据 `ad9361.h`）

| 地址块 | 典型内容 |
| --- | --- |
| `0x000`–`0x01F` | SPI、时钟使能、并口/串口配置、ENSM、校准控制、AuxDAC、Temp |
| `0x040`–`0x05F` | BBPLL 频字、环路滤波 |
| `0x060`–`0x0DF` | Tx FIR 系数、Tx 监视、Tx 衰减、增益校正、正交校准 |
| `0x0F0`–`0x11F` | Rx FIR 系数、Rx 增益（LMT/Full/LPF/数字）、AGC 相关 |
| `0x1A0`–`0x23F` | Rx LO / RF PLL 配置与校准状态 |
| `0x240`–`0x2BF` | Rx/Tx 合成器、电荷泵、VCO 校准状态 |
| `0x3xx` | 杂项 / 未用或保留（视芯片版本） |

精确列表以 `ad9361.h` 为准，不要按上表猜地址。

## 常用寄存器示例（来自 `ad9361.h`）

| 地址 | 宏名 | 作用 |
| --- | --- | --- |
| `0x000` | `REG_SPI_CONF` | SPI 配置 |
| `0x001` | `REG_MULTICHIP_SYNC_AND_TX_MON_CTRL` | 多芯片同步 / Tx Mon |
| `0x002`/`0x003` | `REG_TX/RX_ENABLE_FILTER_CTRL` | 通路与滤波器使能 |
| `0x004` | `REG_INPUT_SELECT` | 数字接口输入选择（CMOS/LVDS、端口） |
| `0x013`–`0x015` | `REG_ENSM_*` | 使能状态机模式与配置 |
| `0x016` | `REG_CALIBRATION_CTRL` | 各类校准触发位 |
| `0x017` | `REG_STATE` | 当前 ENSM / 校准状态 |
| `0x078` | `REG_TX_ATTEN_THRESH` | Tx 衰减阈值相关 |
| `0x109`–`0x10E` | `REG_RX1/2_MANUAL_*_GAIN` | 手动增益 |

## 芯片型号差异

- **AD9361**：2R2T 全功能。
- **AD9363**（PlutoSDR 常见丝印）：频段/带宽受限，寄存器图兼容；Pluto 固件常按 **AD9364（1R1T）** 初始化。
- 读手册时注意：部分 2T/双通道寄存器在 1R1T 板子上不会用到。
