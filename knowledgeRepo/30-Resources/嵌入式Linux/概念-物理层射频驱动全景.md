# 概念：物理层射频驱动全景

## 一句话总结

“物理层射频驱动”不是单个驱动，而是一条分层软件栈：**RFIC 内核驱动（SPI/I2C 控制 + IIO）→ FPGA/JESD 数据面驱动 → 用户态框架（libiio/UHD/SoapySDR）→ RAN PHY 的 radio 后端**；AGC、DPD/CFR、DDC/DUC、TDD、校准等 L1 功能则分布在这四层里，由驱动、FPGA 和芯片固件共同实现。

## 0 全景图

```text
L1 PHY / RAN 应用
   srsRAN / OAI / O-RAN O-RU / 自研 PHY
        ↑  radio backend：UHD / SoapySDR / libiio / 厂商 API
用户态框架与 API
   libiio+iiod | UHD | SoapySDR | LimeSuite | GNU Radio
        ↑  /dev/iio:deviceX、sysfs、mmap、DMA buffer、UIO
内核数据面与板级驱动
   cf_axi_adc_core.c / cf_axi_dds.c / dma-axi-dmac.c / axi_tdd
        ↑  JESD204B/C、LVDS、CMOS、AXI-Stream
RFIC / 收发信机内核驱动
   ad9361.c / ad9371.c / adrv9009.c / adrv9002.c / adrv9025.c ...
        ↑  SPI / I2C 控制、GPIO（reset/ENSM/TDD）
射频前端硬件
   AD936x | ADRV9009/9002/9025 | LMS7002M | RFSoC | USRP | ...
```

## 1 分层职责

| 层            | 职责                                            | 典型代码 / 框架                                                                             |
| ------------ | --------------------------------------------- | ------------------------------------------------------------------------------------- |
| RFIC 驱动      | 芯片初始化、频率/增益/带宽/采样率、校准、ENSM/TDD、SPI 寄存器访问、时钟提供 | `ad9361.c`、`ad9371.c`、`adrv9009.c`、`adrv9002.c`、`adrv9025.c`                          |
| 数据面驱动        | IQ 样本从 PL/JESD 进 DDR、DMA 描述符、IIO buffer、mmap  | `cf_axi_adc_core.c`、`cf_axi_dds.c`、`dma-axi-dmac.c`、`industrialio-buffer-dmaengine.c` |
| 用户态框架        | 设备发现、属性配置、buffer 收发、多设备/多进程访问                 | libiio/iiod、UHD、SoapySDR、LimeSuite                                                    |
| RAN radio 后端 | 把采样率、IQ 格式、时间戳、TDD 时序映射到 PHY 帧结构              | srsRAN radio、OAI radio、O-RAN O-RU 软件                                                  |

## 2 RFIC / 收发信机内核驱动

以下路径为 **ADI Linux 6.1 树**（本仓库 `plutosdr-fw/linux`）的实际位置；mainline 可能不同（部分驱动在 `staging/` 或未完全上游）。

| 芯片 / 平台 | 驱动文件 | 常见载体 | 特点 |
| --- | --- | --- | --- |
| AD9361 / AD9363 / AD9364 | `drivers/iio/adc/ad9361.c`、`ad9361_conv.c`、`ad9361_regs.h` | PlutoSDR（AD9363）、AD-FMCOMMS2/3/4、USRP B200/B210 | 2×2 MIMO、70 MHz–6 GHz、低成本 SDR 首选 |
| AD9371 / AD9375 | `drivers/iio/adc/ad9371.c`、`ad9371_conv.c` | ADRV9371/ADRV9375 评估板、部分 USRP | 宽带、JESD204B、集成观测/DPD 通道 |
| ADRV9009 / ADRV9008 | `drivers/iio/adc/adrv9009.c`、`adrv9009_conv.c` | ADRV9009 评估板、5G 测试床 | 宽带 2×2、ORAN O-RU 常用 |
| ADRV9002 / ADRV9001 | `drivers/iio/adc/navassa/adrv9002.c` 等 | ADRV9002 评估板 | 低功耗宽带、FDD/TDD |
| ADRV9025 / ADRV9026 | `drivers/iio/adc/madura/adrv9025.c` 等 | 高集成 4×4 收发 | 5G massive MIMO / O-RAN RU |
| AD9081 / AD9082 | `drivers/iio/adc/ad9081.c` 等 | 宽带多通道 ADC/DAC | MxFE，配 JESD204B/C |
| AD9208 / AD9680 / AD9467 | `drivers/iio/adc/ad9208.c`、`ad9680.c`、`ad9467.c` | 高速 ADC 接收机 | 宽带回传/监测接收 |
| LMS7002M | LimeSuite（用户态为主） | LimeSDR | 2×2 MIMO，OAI/srsRAN 4G 常用 |
| LMS6002D | libbladeRF（用户态为主） | BladeRF | 较老的 SDR 平台 |
| MAX2837 / MAX5864 | libhackrf（用户态为主） | HackRF | 半双工 SDR |
| RTL2832U + R820T | DVB USB 驱动（`dvb_usb_rtl28xxu`） | RTL-SDR | 仅接收，适合 L1 监测，不是 gNB 射频 |
| Xilinx Zynq UltraScale+ RFSoC | Xilinx `xrfdc`（RF Data Converter）+ PYNQ | RFSoC 开发板、5G 测试床 | 集成 ADC/DAC/DFE，宽带宽多通道 |
| Ettus/NI USRP | UHD（用户态）+ FPGA 镜像 | B2xx/N3xx/X3xx/X4xx | 硬件随型号：AD9364/AD9361、AD9371、RFSoC 等 |

## 3 数据面 / 板级驱动

RFIC 驱动只负责“配置芯片 + 提供 IIO 控制面”，样本搬运由数据面驱动完成：

| 驱动 | 作用 | 与 RFIC 的关系 |
| --- | --- | --- |
| `cf_axi_adc_core.c` | AXI ADC 数据面，注册 IIO DMA buffer | 通过 `spibus-connected` 取 `axiadc_converter`（`ad9361_conv.c` 注册） |
| `cf_axi_dds.c` | TX DDS 数据面（TX 样本流） | 使用 RFIC 的 `TX_SAMPL_CLK`，配 cyclic DMA |
| `dma-axi-dmac.c` | AXI DMAC 的 dmaengine provider | 把 FIFO/Stream 与 DDR 连接，产生完成中断 |
| `industrialio-buffer-dmaengine.c` | IIO buffer ↔ dmaengine 桥 | 用户态 mmap/read 的最终落点 |
| `axi_tdd`（HDL/驱动） | TDD 收发切换与同步 | 与 RFIC 的 ENSM/TXNRX、DMA sync 配合 |

Pluto 的完整链路（控制面 + 数据面 + converter 握手）见 [[学习-Linux-驱动开发-AD9361-从dtsi到驱动调用流程]]。

## 4 用户态框架与 API

| 框架 | 适配对象 | 说明 |
| --- | --- | --- |
| libiio / iiod（ADI） | IIO 设备（AD936x、ADRV9009 等） | 读写属性、创建 buffer、mmap 零拷贝；Pluto 默认栈 |
| UHD（Ettus/NI） | USRP 系列 | 官方 API，屏蔽 FPGA/RFIC 差异，RAN 常用 |
| SoapySDR | 多厂商 SDR | 通用抽象层，可对接 UHD、Lime、BladeRF、RTL-SDR 等；本身不是驱动 |
| LimeSuite | LimeSDR / LMS7002M | 厂商驱动 + API |
| GNU Radio | 通过上述框架接硬件 | 用于快速搭建收发流图，不是底层 RF 驱动 |

## 5 与 L1 功能的对应关系

| L1 / 射频功能 | 主要实现位置 | 线索 |
| --- | --- | --- |
| 增益控制 AGC/MGC | RFIC 驱动 + 芯片内部 | AD9361 dtsi 的 `adi,gc-*`、`adi,mgc-*`、`adi,agc-*` |
| 采样率 / 带宽 / 本振 | RFIC 驱动时钟树 | `clk_set_rate`、RF bandwidth、RX/TX RFPLL |
| DDC/DUC、抽取/内插 | FPGA HDL + RFIC 数字前端 | `cpack`/`upack`、`rx_fir_decimator`、`tx_fir_interpolator` |
| DPD / CFR | RFIC 内部 ARM 或 FPGA | AD9371/ADRV9009 的观测通道、DPD 引擎 |
| TDD 收发切换 | 驱动 + HDL + 芯片 ENSM | `axi_tdd`、ENSM/TXNRX、DMA sync |
| 功率控制 / PA 保护 | 驱动 + 板级 GPIO/芯片 | TX 衰减、过载检测、`adi,tx-attenuation-mdB` |
| 校准（DC/IQ/LO/接口） | RFIC 驱动 + 芯片固件 | `ad9361_setup`、digital interface tune |
| 多通道同步 / PPS | 驱动 + HDL | PPS、sysref、JESD204、`axi_tdd` |

## 6 典型平台组合

| 平台             | RFIC / 数据面                 | 用户态                  | 适合场景                  |
| -------------- | -------------------------- | -------------------- | --------------------- |
| PlutoSDR       | AD9363 + AXI ADC/DDS + DMA | libiio               | 入门 SDR、L1 实验、低成本验证    |
| USRP B2xx      | AD9364/AD9361 + UHD FPGA   | UHD / GNU Radio      | 快速 PHY 原型、教学          |
| USRP X3xx/N3xx | AD9371 / ADRV9009 等        | UHD                  | 宽带、MIMO、RAN 测试        |
| LimeSDR        | LMS7002M                   | LimeSuite / SoapySDR | OAI/srsRAN 4G、灵活实验    |
| RFSoC 板卡       | RFSoC DFE + `xrfdc`        | PYNQ / 自研            | 宽带多通道、5G 原型、ORAN      |
| O-RAN O-RU     | ADRV9009/ADRV9025 + FPGA   | O-RAN 前传栈            | 商用级 O-RU、massive MIMO |

## 7 学习路径建议

1. 先用 **Pluto + AD9361 驱动** 把控制面/数据面链路读通（本仓库已有详细笔记）。
2. 用 [[学习-Linux-内核源码阅读与驱动学习法]] 的 QEMU+GDB 环境练通用机制（VFS/设备模型/中断/锁）。
3. 对照 [[学习-Linux-学习路线]] 执行版阶段 3–6，把 IIO、DMA、mmap、libiio 串起来。
4. 想走 RAN：再补 JESD204B/C、TDD 时序、DPD/CFR、O-RAN 前传，对照 [[MOC-O-RAN开源]] 与 [[MOC-FPGA]]。
5. 想走 RF 驱动开发：横向读 `ad9371.c`、`adrv9009.c`、`adrv9002.c`，对比不同芯片的时钟/校准/数据面抽象。
